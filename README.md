# Zhuo 的个人博客与项目档案

一个使用 Next.js 的中文个人网站，内容聚焦文章、项目与可验证的学习过程。全站为纯静态内容：文章来自仓库内 MDX，项目来自数据注册表，无账号、数据库或上传功能。

运行环境：Node.js 20.9 或更高版本。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run start
```

## 内容结构

- `/`：首页可交互名片卡（我/文章/小项目/更多 Tab）
- `/articles`：MDX 文章列表
- `/projects`：小项目档案列表
- `/about`：个人介绍与联系方式
- `/privacy`：隐私说明

网站事实仅来自公开仓库和已有内容，不补写不可验证的个人经历或成果。
