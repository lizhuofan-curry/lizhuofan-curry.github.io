# 李卓凡的个人博客与项目档案

一个使用 Next.js 静态导出的中文个人网站，内容聚焦文章、项目与可验证的学习过程。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

构建结果位于 `out/`，可直接部署到 GitHub Pages。

## 内容结构

- `/`：主页与互动学习信号场
- `/articles`：MDX 文章、搜索与标签筛选
- `/projects`：项目档案、搜索与标签筛选
- `/about`：个人介绍与联系方式

网站事实仅来自公开仓库和已有内容，不补写不可验证的个人经历或成果。
